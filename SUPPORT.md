# Support

Sentinel is maintained as an open-source safety project. Support is best-effort
and focused on issues that improve the public API/MCP surface, deterministic
gate, signed receipts, verification evidence, and security posture.

## Where To Ask

- Use GitHub issues for reproducible bugs, public-v1 tasks, and documentation
  fixes.
- Use GitHub pull requests for scoped fixes with tests or documentation updates.
- Use GitHub private vulnerability reporting for security-sensitive reports.

Please do not post secrets, signing keys, private audit logs, or sensitive user
conversation data.

## Maintainer Priorities

1. Security reports and deterministic-gate bypasses.
2. Incorrect `APPROVE` decisions for unsafe or false sponsored claims.
3. API, MCP, receipt, and trace regressions.
4. Public-v1 roadmap tasks with tests and clear acceptance evidence.
5. Documentation fixes that keep public claims aligned with implementation.
